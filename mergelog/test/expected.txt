### CLI: Add dry-run mode

Add `--dry-run` and `-n` flags so users can preview file changes before writing
anything to disk.

This also updates `bin/task-runner.ts` and `docs/usage.md`.

### Formatter: Handle nested call expressions

Format `Date.parse`(`job.`startedAt`.valueOf`()) as a single inline-code expression.

Avoid broken output like `Date.parse`(...`valueOf()`) when automatic formatting
is enabled.

### Config: Load local environment files

Load `.env`, .`env.local` and `config/defaults.json` before starting the development
server.

This lets npm run dev demo -- `--watch` work without machine-specific setup.

### API: Add response metadata

Expose `requestId`, `cacheStatus` and `pagination.nextCursor` on SearchResultDto.

Also update `openapi.json` and `src/generated/client.ts` after regenerating the API.

### Build: Reuse cached artifacts

Allow `APP_REUSE_CACHE=1` to skip rebuilding cached bundles when the source hash
has not changed.

### Docs: Add package badges

Add npm badges, license badges and local README links for image-resize and
csv-splitter.

Close #1234

### UI: Use stable keys for calendar rows

Use `week.format`("YYYY-[W]WW") and `day.format`("YYYY-MM-DD") as stable React keys.

This fixes the January rollover when `weekNumber()` returns 1 for dates in the
next year.

### Database: Skip concurrent indexes in transactions

Skip CREATE INDEX CONCURRENTLY when `Transaction.isActive`() or
`CurrentTransaction.get`() is active.

PostgreSQL rejects CREATE INDEX CONCURRENTLY inside a transaction block.

### Content: Render document attachments

Render PDF and text-based attachments dropped into the editor as links.

This keeps `editor.saveChanges`() stable and supports `preview:plain` examples.

### Git: Detect default branch automatically

Prefer @{upstream}, then origin/HEAD, then origin/main, origin/master, main and
master.

Avoid failing on repositories where the default branch is not origin/master.

### Release: Rename package to changelog-md

Rename the package and executable from git-summary to changelog-md because the
original npm package name was unavailable.

### Paths: Format source and config files

Format `src/index.ts`, `packages/web/tsconfig.json`, `.env` and `.prettierrc` as code.

Also format nested paths such as `apps/demo/src/client.ts`.

### Formatter: Keep all-uppercase words plain

### Tests: Add fixture mode

### Worker: Restart after clean shutdown
